Examples

As in the `usage section <usage.html>`_, we will assume you have imported the package with the alias ``fld``, and that the ``numpy`` and ``astropy.constants``, ``astropy.units`` modules are also loaded:

.. code-block:: python

    import pyFLD as fld
    import numpy as np
    from astropy import constants as const, units as u
